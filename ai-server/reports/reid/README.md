# ReID Evaluation Reports

This directory stores model evaluation reports generated by the calibration pipeline.

## Directory structure (per model version)

```
reports/reid/<model_version>/
├── metrics.json          # Full metrics: FAR, FMR, FNMR, EER, TAR@FAR=0.1%
├── roc.png               # ROC curve
├── per_species.csv       # Per-species breakdown
├── calibration.json      # Derived thresholds from this evaluation
├── dataset_manifest.json # Which data was used (individuals, sessions, devices)
└── confusion_matrix.png  # Top-k confusion
```

## Requirements for valid calibration

1. **Independent dataset**: frames from the SAME video must NEVER appear in both train and test
2. **Split by**: individual, video, session, day
3. **Minimum**: 10 identities × 3 sessions per species
4. **Cross-conditions**: different days, devices, lighting, wet/dry, left/right
5. **Target**: FAR ≤ 0.1% before enabling auto_match in production
